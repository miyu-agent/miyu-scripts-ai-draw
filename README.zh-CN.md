# AI 生图

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `ai_draw`，它按照文字描述画一张图，也可以带上参考图。它使用 OpenAI 的 GPT 生图，也支持 RightCode 这类兼容的中转服务。画好的图会存进用户的图片目录，同时附给 AI 查看；如果要给人看，AI 会再用 `show` 打开它。

## 设置

这个软件包的配置项在设置的 `软件包` 页里，找到 `AI 生图` 即可：

| 项 | 默认 | 说明 |
|---|---|---|
| `接口地址` | `https://api.openai.com/v1` | 使用 OpenAI 时不需要修改；使用 RightCode 时填写 `https://api.site/draw`（旧地址 `https://www.right.codes/draw` 在海外仍然可以使用）。如果地址末尾没有 `/v1` 这类版本号，工具会自动补上 `/v1` |
| `API Key` | 无 | 必填，填写服务的密钥 |
| `模型` | `gpt-image-1` | 在 RightCode 上是 `gpt-image-2` |
| `默认宽高比` | `auto` | AI 没有指定宽高比时使用这个值 |
| `默认清晰度` | `1K` | 只有 RightCode 识别这一项，实际尺寸由它决定（实测时 1K 的方图是 1254×1254，2K 的 16:9 是 1672×940） |
| `固定尺寸` | 无 | 例如 `1024x1024`；填写以后每张图都使用这个尺寸，不再考虑宽高比和清晰度 |
| `画质` | `auto` | 可选 `low`、`medium`、`high`；选 `auto` 时不传这个参数 |
| `图片格式` | `png` | 只有 GPT Image 模型识别这一项；`jpeg`、`webp` 的文件更小 |
| `背景` | `auto` | 只有 GPT Image 模型识别这一项；透明背景需要搭配 `png` 或 `webp` |
| `内容审核` | `auto` | 只有 OpenAI 的 GPT Image 模型识别这一项；`low` 的审核宽松一些 |
| `超时（秒）` | 240 | 范围是 30–280 |

所有配置项都在调用的那一刻读取，所以修改以后下一次调用就会生效。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `prompt` | 必填，要画的内容 |
| `reference_images` | 参考图，最多 8 张：可以是本地文件路径，也可以是 http(s) 网址；支持 PNG、JPEG、WebP，每张不超过 20 MiB。用户在聊天里发送的图片保存在会话的附件目录里，AI 能看到它的路径，按照这个路径传入即可 |
| `aspect_ratio` | `auto`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9`；不填写时使用设置里的值 |
| `resolution` | `1K`、`2K`、`4K`；不填写时使用设置里的值 |

## 行为

这一节说明工具如何选择接口、决定尺寸、保存图片和处理网络请求。

- **工具根据接口地址选择两套接口中的一套**：如果接口地址的域名是 `api.site`、`right.codes` 或 `rightapi.ai`，就使用 RightCode 的接口：参考图以 base64 数组的形式放进 `/v1/images/generations` 的 JSON，并带上宽高比和它的尺寸表。其他地址使用 OpenAI 的接口：没有参考图时使用 `/v1/images/generations`，有参考图时使用 `/v1/images/edits`（multipart，字段是 `image[]`）。
- 尺寸：对于 RightCode，工具按宽高比和清晰度查表得出请求的尺寸（尺寸表沿用旧版，2K、4K 请求的长边都是 2048），返回的图片多大由 RightCode 决定；对于 GPT Image 模型，竖图是 `1024x1536`，横图是 `1536x1024`，方图是 `1024x1024`，`auto` 交给服务决定；其他模型（DALL·E 这类）使用 `1024x1792`、`1792x1024`、`1024x1024`。
- 图片保存在图片目录（`MIYU_PICTURES_DIR`）下的 `AI生图/<时间>-<提示词开头>.png`，不会自动清理。群聊、陌生人私聊这类会话没有图片目录，图片会改存到脚本缓存目录（`MIYU_CACHE_DIR`）下的 `images/`，只保留最近的 20 张。工具不会往工作区里写任何东西。
- 附给 AI 查看的图片要符合 Miyu 的规格：不超过 5 MiB，每条边不超过 8000 像素；超出的图片只保存、不附上（把图片格式换成 `jpeg` 或 `webp`，文件就会变小）。
- 脚本不自己判断谁能使用、参考图能从哪里读取：群聊和陌生人私聊使用哪个预设由场所规则决定，如果你不想让那些会话消耗你的额度，就在对应的预设里关闭 `AI 生图`；那些会话的沙盒本来就读不到本机其他位置的文件。
- 参考图的网址和服务返回的图片网址只允许连接公网地址，每一次跳转都会检查，并且实际连接的就是检查过的那个地址（代理使用的假 IP 段 198.18.0.0/15 会放行；使用代理时，目标地址由代理解析）；和接口地址同一个主机的网址不检查，所以本机的中转服务也可以使用。接口地址本身由管理员填写，不做检查。
- 出错时，工具会返回服务的原始报错（最多 500 字，其中的密钥会替换成 `***`）。

脚本没有写 `Clicall`：因为这件工具会消耗额度，所以不允许 AI 在命令里批量调用它。清单里写了 `needs = ["images"]`，所以在无法显示图片的会话（语音）里，整个软件包都不会启用。

这些配置项需要 Miyu 支持脚本软件包带 `[settings]`，并且在运行脚本时把配置的值放进 `MIYU_SETTINGS_JSON`（其中只有这个软件包自己的项，键不带软件包编号，密钥是真实的值）。

这个软件包只使用 Python 标准库。
