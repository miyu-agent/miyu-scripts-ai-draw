# AI 生图

Miyu 的脚本包，带一件工具 `ai_draw`：照文字画一张图，可以带参考图。用 OpenAI 的 GPT 生图，也接 RightCode 这类兼容的中转。画好的图存进用户的图片目录，并附上给 AI 看；要给人看，AI 再用 `show` 打开它。

## 设置

在设置的「软件包」页找「AI 生图」：

| 项 | 默认 | 说明 |
|---|---|---|
| 接口地址 | `https://api.openai.com/v1` | 用 OpenAI 的不用改；用 RightCode 的填 `https://www.right.codes/draw`。末尾没有 `/v1` 这类版本号的会自动补上 `/v1` |
| API Key | 无 | 必填 |
| 模型 | `gpt-image-1` | RightCode 上是 `gpt-image-2` |
| 默认宽高比 | `auto` | AI 没指定时用这个 |
| 默认清晰度 | `1K` | 只有 RightCode 认，实际多大由它定（10-30 实测：1K 方图 1254×1254，2K 的 16:9 是 1672×940） |
| 固定尺寸 | 无 | 例如 `1024x1024`；填了就每张都照它，宽高比、清晰度不看 |
| 画质 | `auto` | `low`、`medium`、`high`；`auto` 不传 |
| 图片格式 | `png` | 只有 GPT Image 模型认；`jpeg`、`webp` 小 |
| 背景 | `auto` | 只有 GPT Image 模型认；透明背景要配 png 或 webp |
| 内容审核 | `auto` | 只有 OpenAI 的 GPT Image 模型认；`low` 审得松一些 |
| 超时（秒） | 240 | 30–280 |

都是调用那一刻读，改了下一次就用上。

## 参数

| 参数 | 说明 |
|---|---|
| `prompt` | 必填，画什么 |
| `reference_images` | 参考图，至多 8 张：本地文件路径或 http(s) 网址；PNG、JPEG、WebP，一张不超过 20 MiB。人在聊天里发的图落在会话的附件目录里，AI 看得到路径，照那个路径传 |
| `aspect_ratio` | `auto`、`1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`4:5`、`5:4`、`9:16`、`16:9`、`21:9`；不给照设置 |
| `resolution` | `1K`、`2K`、`4K`；不给照设置 |

## 行为

- **两套接口照地址认**：接口地址的域名是 `right.codes` 的走 RightCode 那套：参考图以 base64 数组放进 `/v1/images/generations` 的 JSON，带宽高比和它的尺寸表。别的走 OpenAI 那套：没有参考图的走 `/v1/images/generations`，有的走 `/v1/images/edits`（multipart，字段 `image[]`）。
- 尺寸：RightCode 照宽高比和清晰度查表请求（表照旧版，2K、4K 请求长边 2048），交回多大由它定；GPT Image 模型竖的 `1024x1536`、横的 `1536x1024`、方的 `1024x1024`、`auto` 交给服务；别的模型（DALL·E 这类）`1024x1792`、`1792x1024`、`1024x1024`。
- 存到图片目录（MIYU_PICTURES_DIR）下的 `AI生图/<时间>-<提示词开头>.png`，不自动清。群聊、陌生人私聊这类会话没有图片目录，退回脚本缓存目录（MIYU_SCRIPT_CACHE_DIR）下的 `images/`，只留最近 20 张。不往工作区写东西。
- 附给 AI 看的图照 Miyu 的规格：不超过 5 MiB、每边不超过 8000 像素；大了的只存不附（图片格式换成 jpeg、webp 就小了）。
- 谁能用、参考图读得到哪，脚本不自己管：群、陌生人私聊用哪个预设由场所规则定，不想让那里花你额度的，在那个预设里关掉「AI 生图」；那些会话的沙盒本来就读不到本机别处的文件。
- 参考图的网址、服务交回的图片网址只连公网地址，每一次跳转都查（代理的假 IP 段 198.18.0.0/15 放行）；和接口地址同一个主机的不查（本机的中转也能用）。接口地址本身是管理员填的，不查。
- 出错时把服务的原话交回（至多 500 字，里面的 API Key 换成 `***`）。

`Clicall` 不写：花额度的不给 AI 在命令里批量调。清单写了 `needs = ["images"]`，显示不了图片的会话（语音）里整包不开。

配置项要 Miyu 让脚本包带 `[settings]`、跑脚本时把值放进 `MIYU_SETTINGS_JSON`（这个包自己的项，键不带包编号，密钥是真值）。

只用 Python 标准库。
