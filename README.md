# AI drawing

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `ai_draw`, which draws a picture from a text description, optionally starting from reference images. It uses OpenAI's GPT image generation and also works with compatible relay services such as RightCode. The finished picture is saved into the user's Pictures folder and attached for the AI to look at; to show it to a person, the AI then opens it with `show`.

## Settings

The settings for this package are on the packages page of the settings; find `AI drawing` there:

| Setting | Default | Description |
|---|---|---|
| `API address` | `https://api.openai.com/v1` | Leave it as is for OpenAI; for RightCode, enter `https://api.site/draw` (the old address `https://www.right.codes/draw` still works overseas). If the address does not end in a version such as `/v1`, the tool appends `/v1` automatically |
| `API key` | None | Required: the key for the service |
| `Model` | `gpt-image-1` | On RightCode it is `gpt-image-2` |
| `Default aspect ratio` | `auto` | Used when the AI does not specify an aspect ratio |
| `Default resolution` | `1K` | Only RightCode uses this setting, and it decides the actual size itself (in testing, a 1K square image came out at 1254×1254 and a 2K 16:9 image at 1672×940) |
| `Fixed size` | None | For example `1024x1024`; once it is set, every image uses this size and the aspect ratio and resolution are ignored |
| `Quality` | `auto` | One of `low`, `medium`, `high`; with `auto` the parameter is not sent |
| `File format` | `png` | Only GPT Image models use this setting; `jpeg` and `webp` files are smaller |
| `Background` | `auto` | Only GPT Image models use this setting; a transparent background needs `png` or `webp` |
| `Content filter` | `auto` | Only OpenAI's GPT Image models use this setting; `low` filters less strictly |
| `Timeout (seconds)` | 240 | The range is 30–280 |

Every setting is read at the moment of the call, so a change takes effect on the next call.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `prompt` | Required: what to draw |
| `reference_images` | Reference images, at most 8: local file paths or http(s) URLs; PNG, JPEG and WebP are supported, each at most 20 MiB. Images that a user sends in the chat are saved in the session's attachment folder, and the AI can see their paths; pass those paths |
| `aspect_ratio` | `auto`, `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`; when it is left out, the value from the settings is used |
| `resolution` | `1K`, `2K`, `4K`; when it is left out, the value from the settings is used |

## Behavior

This section explains how the tool picks an API, decides the size, saves pictures and handles network requests.

- **The tool picks one of two APIs based on the API address**: if the domain of the API address is `api.site`, `right.codes` or `rightapi.ai`, it uses the RightCode API: reference images go into the JSON of `/v1/images/generations` as a base64 array, together with the aspect ratio and RightCode's size table. Any other address uses the OpenAI API: `/v1/images/generations` without reference images, and `/v1/images/edits` (multipart, field `image[]`) with them.
- Size: for RightCode, the tool looks up the requested size from the aspect ratio and resolution (the size table follows the old version, and 2K and 4K both request a long side of 2048), and RightCode decides how large the returned image is; for GPT Image models, portrait is `1024x1536`, landscape is `1536x1024`, square is `1024x1024`, and `auto` is left to the service; other models (such as DALL·E) use `1024x1792`, `1792x1024` and `1024x1024`.
- Pictures are saved in the Pictures folder (`MIYU_PICTURES_DIR`) as `AI生图/<time>-<start of prompt>.png` and are never cleaned up automatically. Sessions such as group chats and private chats with strangers have no Pictures folder, so pictures go into `images/` in the script cache folder (`MIYU_CACHE_DIR`) instead, where only the latest 20 are kept. The tool never writes anything into the workspace.
- Pictures attached for the AI must meet Miyu's limits: at most 5 MiB and at most 8000 pixels on each side; larger pictures are saved but not attached (switching the file format to `jpeg` or `webp` makes the file smaller).
- The script does not decide by itself who may use it or where reference images may be read from: the venue rules decide which preset group chats and private chats with strangers use, so if you do not want those sessions to spend your credit, turn off `AI drawing` in that preset; the sandbox of those sessions cannot read files elsewhere on the machine anyway.
- Reference image URLs and the image URLs returned by the service may only connect to public addresses; every redirect is checked, and the connection goes to exactly the address that was checked (the fake IP range 198.18.0.0/15 used by proxies is allowed; when a proxy is used, the proxy resolves the target); URLs on the same host as the API address are not checked, so a relay on the local machine also works. The API address itself is entered by the administrator and is not checked.
- On an error, the tool returns the service's original message (at most 500 characters, with the key replaced by `***`).

The script does not set `Clicall`: because the tool spends credit, the AI is not allowed to call it in bulk from a command. The manifest says `needs = ["images"]`, so in sessions that cannot show images (voice), the whole package is disabled.

These settings require Miyu to let script packages carry `[settings]` and to put the values into `MIYU_SETTINGS_JSON` when it runs the script (only this package's own settings, with keys that do not include the package id, and the key as its actual value).

The package uses only the Python standard library.
